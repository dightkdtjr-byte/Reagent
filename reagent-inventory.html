MSDS PDF는 backups/msds 폴더에 '품목코드_물질명_CAS.pdf' 이름으로 별도 보관합니다. 백업 JSON 파일만 복사하면 PDF는 따라가지 않으니, 다른 PC로 옮기거나 보관할 때는 「묶음 저장」으로 만든 zip 한 파일을 쓰세요. 「백업 불러오기」는 JSON과 zip 묶음 모두 받습니다. 보관 개수는 재고 백업 기준이며, MSDS는 남아 있는 백업에서 사용하는 파일만 유지합니다.

검사는 파일 읽기·JSON 형식·필수 데이터 구조를 확인합니다. 프로그램이 꺼져 있을 때는 자동 백업이 실행되지 않습니다.

GHS 분류 · MSDS 비치 관리

품목별 GHS 분류(그림문자·신호어·H/P 문구)는 각 품목 상세 화면에서 입력합니다. 입력한 분류는 재고 목록, 입출고 확인창, QR 라벨에 표시됩니다.
MSDS 검토 주기
MSDS 검토일(없으면 작성·개정일)을 기준으로 다음 검토 예정일을 계산해 목록과 재고현황에 표시합니다.
등록할 때 MSDS 자동 받기
CAS 번호를 넣어 등록하면 뒤에서 국문 MSDS를 받아 첨부하고 GHS를 채웁니다 (안전보건공단 KOSHA). 인터넷이 필요합니다.
QR 라벨에 GHS 그림문자·신호어 인쇄
라벨 아래쪽 ID 옆에 그림문자(최대 5개)와 신호어를 함께 인쇄합니다.
